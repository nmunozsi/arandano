# Aggressive Worker-Time Reduction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce per-task wall time from 907s (post-Phase 3) to ≤450s by parallelizing gates, exercising context injection, inlining prompt content, trimming Claude's tool surface, skipping stale gitnexus reindex, and pooling warm containers. Add the instrumentation needed to measure each step.

**Architecture:** Touch five surfaces — worker driver (prompt + tool flags + stream-json parser), runGates.ts (Promise.all), DockerExecutor (gitnexus mtime check + WarmContainerPool with persistent per-slot workspaces), bench surfaces (token & per-tool columns), config (`executor.warm_pool_size`, `gates.parallel`).

**Tech Stack:** TypeScript (ESM, node22), oclif 4, vitest, dockerode. No new runtime dependencies.

**Reference spec:** `docs/perf-optimization/spec.md`.

**Scope deferrals (deliberate):**

- Multi-provider CLI selection (OpenCode, Gemini, Codex) — separate future spec.
- Direct Anthropic API integration in the worker — only investigated in T7.
- Coverage-delta-vs-base-branch as a gate — deferred.
- Security gate as required — deferred.
