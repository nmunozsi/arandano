# arandano Phase 3 — Performance Instrumentation & Improvements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instrument every host + worker phase, establish a baseline for the three-helpers plan, then apply data-driven improvements with measured deltas. Target: ≥40% per-task wall-time reduction.

**Architecture:** A `PerfRecorder` utility in `@arandano/core` (and a vendored copy in the worker repo) is used to wrap each phase. The worker writes a per-run `timings.json`; the host (`DockerExecutor`) merges its own timings with the worker's and appends one row to `.arandano/bench.csv`. A new `arandano bench` read-only command summarises the CSV. After a baseline run, a decision-gate task (T6) selects which of three tentative improvements to actually implement before measuring again.

**Tech Stack:** TypeScript (ESM, node22), oclif 4, vitest, dockerode. No new runtime dependencies.

**Reference spec:** `docs/perf-instrumentation/spec.md`.

**Scope deferrals (deliberate):**

- Parallelizing quality gates inside the worker.
- Container reuse across tasks.
- Claude Code prompting / tool-call reduction.
